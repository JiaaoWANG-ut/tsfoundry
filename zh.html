过渡态搜索 · AI 自主发明 · 严格验证

只从初态出发，找到过渡态。

过渡态是化学反应的底层根本：它决定发生哪个反应、反应有多快。Transition Foundry 融合了过去所有主流的过渡态算法，并利用最前沿的 AI 模型，自主产生在完整 3N 维构型空间中搜索一阶鞍点的新算法。每个想法都在从未见过的反应上检验，只有胜出才被保留。

解决的问题

反应研究最难的，是过渡态

在催化剂表面和分子筛孔道里找过渡态，通常意味着先猜产物、反复调 NEB 链、一次次重跑跑偏的 dimer。Transition Foundry 解决的正是这些瓶颈。

⇢

不需要终态

NEB 和 CI-NEB 必须先知道产物才能开始。

只给初态。键坐标松弛扫描提出反应可能的去向，搜索替你找到鞍点和产物。

⋔

得到机理，而不只是一条路径

双端方法对一个猜测的产物只返回一个过渡态。

一次运行返回初态周围找到的所有不同的已认证鞍点，附能垒、反应能和产物，去重并排序：分子筛演示中每次运行 7 个，基准测试中平均每次运行 6.3 个。

↯

快好几倍

随机起点的 dimer 把大部分精力花在重复和失败上。

在 39 个留出反应上，每 CPU 小时的已验证鞍点数是 ASE dimer 的 4.2–6.2 倍；第一个已验证鞍点的中位用时 9.5 CPU 秒，而不是 92 CPU 秒。

✓

没有假鞍点

在我们的基准里，约 29% 收敛的 CI-NEB 链并没有停在一阶鞍点上。

每个报告的鞍点都恰好有一个精确 Hessian 负本征值，并经过两侧下坡验证：一侧回到你的初态，另一侧到达产物极小点。

⬡

专为复杂环境

台阶、空位、单原子合金和分子筛孔道会困住通用优化器。

基准测试覆盖 fcc(221) 与 bcc(211) 台阶、hcp(10-10)、空位、单原子合金，以及 9 种分子筛骨架（最多 254 个原子）；金属与分子筛的搜索引擎自动选择。

⌘

无需专家调参

每种方法都有自己的参数、步长和失败方式。

一条命令加一个目标：fast、complete、lowbarrier、network 或 dft。也可以交给你的编程 agent：工作区自带 AGENTS.md 入口。

如何构建

一个会发明鞍点搜索算法、并且必须自证的 AI 研究循环

前沿的编排模型提出想法，并行的 agent 各用一个 CPU 核实现并测试，固定的协议决定去留。算法直接在体系完整的 3N 维笛卡尔空间中工作，不需要人工指定反应坐标。

融合

20+ 种方法

dimer 与 κ-dimer、Lanczos、Hessian 本征向量跟踪与 P-RFO、Sella（RS-PRFO）、牛顿轨迹与约束松弛扫描、AFIR 式外力以及 (CI-)NEB，统一在一个引擎、一个验证器、一本计费账里。

发明

306 个实验

389 轮研究。每轮提出一个数学改动（新的约束曲面、曲率控制、记忆、引擎路由）并实现它。

验证

122 项有效

预注册检验：开发集筛选、留出池一次性确认、密封集只在总决赛打开。失败也全部保留：140 个实验为阴性，35 个无定论。

发布

75 项进入引擎

经过验证的算法与易用性、安全性改进一起进入同一个软件包（共 117 项合并）。默认流程：松弛扫描 → 金属用 Sella、其余用 dimer → 精确 Hessian 认证。

部分已进入引擎、经过验证的想法：

键长等值面驱动κ-dimer 能壳路径分散的键坐标扫描带记忆的单次长搜索惰性 dimer 转动金属表面行走牵绳精确 Hessian 证书Sella → 验证器模式接力Sella 停滞即停安全的单侧判定分子筛复发闸门模型预测 dimer 转动
结果

同样的 CPU 时间，更多已验证鞍点

TF-B1 基准，运行前已预注册：最终测试集中 39 个从未用于调参的密封反应（27 个金属台阶、空位与单原子合金上的反应，12 个 9 种分子筛骨架中的酸位质子转移；30–254 个原子），2 个种子，每个任务一个 Perlmutter CPU 核，NEP89，共 780 个任务，全部完成。只有精确 Hessian 恰有一个负本征值的鞍点才计数；搜索类方法还要求两侧下坡都连通。所有方法使用同一个验证器和同一套 CPU 计时。

换句话说

  • 在 ASE dimer 于每个案例、每个种子上花费的同样 CPU 时间内，默认预设找到 445 个已验证鞍点，dimer 为 101 个。
  • 不给产物时，Transition Foundry 找回参考过渡态的频率与拿到产物的 CI-NEB 相当：默认预设 78 次运行中 38 次（49%），long-more-auto-81 46 次（59%）；CI-NEB 为 39 个案例中 21 个（54%）。每次运行平均还返回 6.3 个已验证鞍点。
  • 已知产物时 CI-NEB 很快（每个案例中位 9.4 CPU 秒）。在同一案例上截止到 CI-NEB 所用的 CPU 时间，默认预设已找到 68 个已验证鞍点，CI-NEB 为 52 个（CI-NEB 按每个种子各计一次）；但手握产物的 CI-NEB 在这段时间内命中参考过渡态的次数更多（42 对 8）。

CI-NEB 回答的是另一个问题：已知产物时的那一个过渡态。我们对它很宽松：力收敛阈值宽 25 倍（0.05 eV/Å）、不检查连通性、并取两种协议中更好的一个作为基线。在分子筛上与它的对比噪声太大，无法下结论（0.91–2.24 倍，置信区间都包含 1）。

使用

交给你的 agent

Transition Foundry 为编程 agent 驱动而设计。让 agent 遍历工作区，再告诉它你关心的具体反应路径，它会选出不需要终态、效率最高的搜索方案，运行并返回经过认证的过渡态。

  1. 1把 Transition Foundry 工作区交给你的 agent（访问需申请）。
  2. 2描述你的体系和关心的反应，或者只给初态。
  3. 3拿到经过认证的过渡态：能垒、产物、IS/TS/FS 结构，以及可直接用于 DFT 的输入。
给 agent 的提示词
先阅读 Transition Foundry 工作区 <路径> 中的 AGENTS.md，再阅读它指向的文档。 我的体系：<催化剂 / 表面 / 分子筛，吸附物>。初态：<IS.extxyz，或者说明如何搭建>。 关心的反应：<例如 CH3OH 的 C–H 断裂、酸位质子转移>。 为这个目标选择不需要终态、效率最高的预设，用 `dimer-explore doctor` 检查安装，在计算节点上运行搜索，报告每个经过认证的过渡态及其能垒、反应能和产物，并给出 IS/TS/FS 结构文件。不确定的地方请标出。
或者自己运行
pip install -e '/path/to/dimer-exploration[hessian,sella]'
# 检查模型、依赖，估计内存与用时
dimer-explore doctor --structure IS.extxyz
# 默认：fast，不需要终态
dimer-explore explore IS.extxyz --out run
# 找到更多机理
dimer-explore explore IS.extxyz --goal complete --out run2
# IS/TS/FS 三维查看器
dimer-explore view run

选择目标

目标适用场景运行内容
fast想要每 CPU 小时最多的已验证过渡态（默认）long-best-auto-80
complete想从一次搜索得到更多机理--more：额外起点、位点跳跃、重走
lowbarrier只关心动力学上相关的步骤能垒上限以下的鞍点（--max-barrier，默认 1.5 eV）
network还需要后续步骤--network-depth 2：产物成为新的初态
dft之后要用 DFT 精修默认 + 指前因子 + VASP/CP2K 输入

输出：saddles.csv、saddles.extxyz（每个鞍点的 IS、TS 和产物）、summary.md、mechanism.md、dft/。中断的运行用 --resume 继续。

诚实的局限

它不声称什么

NEP89 能量

所有数字都在 NEP89 机器学习势上。能垒用于排序和筛选，请用 DFT 确认。直接用于 DFT 搜索时的节省尚未得到证明。

高效，但不是穷举

在 85 个开发初态上，穷举普查找到 1,296 个严格鞍点，默认两种子并集覆盖约 490 个。需要更全面时用 complete 或 network。

CI-NEB 并未过时

如果你已经知道产物、只要那一条路径，CI-NEB 足够快也足够准。Transition Foundry 用于你不知道反应去向的时候。

测试范围

金属表面（台阶、空位、单原子合金）和分子筛，30–254 个原子；NEP89 支持的中性、无自旋体系。
